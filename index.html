01

Pendahuluan

Latar belakang mengambil topik keamanan website

📢

Website Berita BTIKP adalah sarana informasi utama pendidikan di Kalsel.

🚨

Ditemukan banyak konten ilegal (judi online) yang tidak etis disusupkan pihak luar.

⚠️

Sistem lama memiliki celah keamanan karena minimnya validasi input data.

📉

Dampak negatif berupa turunnya kredibilitas instansi dan inefisiensi kerja admin.

02

Tujuan Penelitian

Target utama yang ingin dicapai dalam laporan PKL ini

🎯

Membangun ulang website dengan framework Laravel yang lebih aman dan modern.

🛡️

Implementasi Rate Limiting untuk mencegah serangan Brute Force pada login.

🔍

Penerapan Input Validation ketat untuk menolak injeksi konten berbahaya.

📝

Menambahkan Activity Logging untuk memantau semua jejak aktivitas pengguna.

03

Manfaat Penelitian

Dampak positif implementasi sistem baru

🏢

Bagi Instansi:
Memulihkan citra dan kepercayaan publik terhadap website resmi.

👨‍💻

Bagi Administrator:
Efisiensi kerja meningkat, bebas dari tugas pembersihan spam manual.

👥

Bagi Masyarakat:
Akses informasi pendidikan yang nyaman, aman, dan terpercaya.

🎓

Bagi Penulis:
Penerapan langsung ilmu Cyber Security pada kasus nyata.

04

Kesimpulan

Evaluasi hasil implementasi sistem keamanan

✅

Sistem keamanan baru berhasil menolak input berbahaya secara otomatis.

🔒

Fitur Rate Limiting efektif memblokir akses login yang mencurigakan (brute force).

📊

Activity Logging berhasil merekam jejak audit untuk transparansi sistem.

🚀

Website BTIKP kini berjalan lebih aman, stabil, dan mudah dikelola.

05

Saran

Rekomendasi untuk pengembangan di masa depan

🔐

Penggunaan protokol HTTPS (SSL/TLS) pada server produksi untuk mengenkripsi lalu lintas data antara browser dan server.

🤖

Penambahan fitur CAPTCHA (Google reCAPTCHA) pada formulir login dan input publik untuk menambah lapisan keamanan terhadap bot otomatis.

💾

Menerapkan prosedur Backup Berkala basis data secara otomatis (harian/mingguan) guna mengantisipasi risiko kehilangan data.
